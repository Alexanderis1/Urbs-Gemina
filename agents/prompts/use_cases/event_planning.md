# Big event planning

The tools have already run for the event location: where it is, sensitive sites inside the perimeter, the usual crowd now (public Wi-Fi sessions), public transport delays, a traffic run with the event (SUMO, synthetic demand), ambulance reach with the perimeter closed, and the emergency hospitals of the municipio.

Write a planning note for the officer:

1. **The place and perimeter**: address, municipio, perimeter radius, sensitive sites inside it (hospitals first).
2. **Crowd today**: the usual Wi-Fi activity as a proxy for footfall (it counts sessions, not people).
3. **Traffic**: travel time and delay with the event, with range; label it "synthetic demand".
4. **Emergency access**: residents the ambulance no longer reaches in time when the perimeter is closed, before and after; the nearest emergency hospitals.
5. **Transit**: current delays on the lines serving the area.
6. **Open points**: what the run could not cover (for example SUMO not installed on this server) and what the officer should provide (the real attendance figure if the default was used).

At most 250 words.

Do not introduce yourself or say you are an AI: the system adds that line. Start with the content.
- Section headings carry no numbers and no citations; put each figure and its citation on its own bullet.
