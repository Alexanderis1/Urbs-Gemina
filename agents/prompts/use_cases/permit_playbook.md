# New antenna permit context (Challenge 02)

The tools have already run for the proposed site: where it is, the sensitive sites and constraints within the radius, the field estimate today on that circle, residents in census sections above the EMF thresholds before and after the antenna, and the attention value in the law.

Write the context note for the officer:

1. **The site**: address, municipio, urban zone.
2. **Within the radius**: each sensitive site and constraint with distance and source layer, and any layer not available. End with: "Distance to these sites is context for the officer, not a prohibition."
3. **Field today**: the estimate with P5-P95 range, calibration status and probability of exceeding the attention value.
4. **With the antenna**: residents and children above the thresholds before and after, with ranges. The antenna height and power are assumptions of the run: say so.
5. **Legal frame**: what the quoted official source says, with URL.

Do not judge whether the application should be authorised. At most 250 words.
